A build on a node where EESSI detects an NVIDIA accelerator target, such as `accel/nvidia/cc90`, passes that compute capability to EasyBuild as `EASYBUILD_CUDA_COMPUTE_CAPABILITIES` and says so, unless the caller set the variable or gave `--cuda-compute-capabilities`. Without one, the Kokkos easyblock left its CUDA backend off and installed an OpenMP library under the `-CUDA-` module name, and a program built against it ran on the host.
