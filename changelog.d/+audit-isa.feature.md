`eb-local audit-isa PATH --target TARGET` disassembles the ELF files under PATH with `objdump` and reports every instruction that needs a CPU feature the EESSI target lacks, per file with counts, for x86-64 (AVX-512, AVX-VNNI, AMX and the rest) and aarch64 (SVE, SVE2, BF16, I8MM and the rest). Packages that choose their instruction set at run time are listed as dispatch and do not fail the audit; `--allow FILE` replaces that list. It exits 0 when clean, 1 when an instruction exceeds the target, and 2 on usage or tool errors.
