`eb-local eb` sources the EESSI init, loads `EESSI-extend` and runs `eb`, with no site file and no Slurm job. Exactly one of `EESSI_USER_INSTALL`, `EESSI_PROJECT_INSTALL`, `EESSI_SITE_INSTALL` and `EESSI_CVMFS_INSTALL` may be set, and a present empty value counts as set. A user prefix is created when its value is non-empty, or at `$HOME/EESSI` when none of the four is set; a project, site or cvmfs prefix is not created. The process umask is 077, 002 or 022 for those modes, and EasyBuild keeps the umask, the sticky bit and the hooks the module sets. `EB_LOCAL_EESSI_EXTEND=1` selects the same launcher when every argument belongs to `eb`.
