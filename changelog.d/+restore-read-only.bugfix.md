`eb-local restore NAME/VERSION` brings back from the trash what `uninstall` moved there, for every CPU target, and takes write permission away again, as EasyBuild leaves an installation. `uninstall` made every file writable before `rtrash put`, so `rtrash restore` brought an installation back writable; it now makes only the directories writable, which rtrash needs to move a directory and to empty the trash, and the files keep their read-only modes.
